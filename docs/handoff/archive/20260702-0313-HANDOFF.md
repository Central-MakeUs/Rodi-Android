## Context (왜)
현재 `Button`(M3)을 스타일링하는 코드가 3곳에 중복돼 있고, 그중 2곳은 `containerColor`/`contentColor`
조합이 동일한데도 매번 새로 작성돼 있다:

- `feature/entry/EntryComponents.kt:142` — `PrimaryButton` (48dp, `RodiRadius.md`(12dp),
  primary600/white, disabled gray300/gray500). `EntryScaffold`(같은 파일 55~121행)에서만 호출된다.
- `feature/home/components/sheet/CourseDetailContent.kt:165` — "경로 안내" 버튼. 48dp,
  `RoundedCornerShape(12.dp)`, primary600/white, disabled 색 미지정(현재 `enabled` 파라미터
  자체가 없어 disabled 상태로 진입하지 않음).
- `feature/home/components/sheet/ParkingDetailContent.kt:133` — "경로 안내" 버튼. 48dp,
  `RoundedCornerShape(8.dp)`(다른 두 곳과 다르게 `RodiRadius.sm`), 나머지 색상 동일.

세 곳 다 `feature` 모듈이 `androidx.compose.material3.Button`/`ButtonDefaults`를 직접 import해서
스타일링하고 있어 컴포넌트 자체가 중복된 상태다. 이번 작업은 이 중복을 `core:ui`의 공통 컴포저블
`RodiButton`으로 정리한다. 현재 코드베이스에 "secondary" 버튼 실사용처는 없지만, 요구사항에 따라
향후 재사용을 위해 `RodiButtonVariant`로 Primary/Secondary 두 스타일을 모두 지원하도록 만든다
(Secondary 색상은 아래 Spec에 정확히 명시 — 임의 추측 금지).

## Spec (무엇을·어떻게)

### 1. `core:ui`에 `RodiButton` 컴포저블 추가
새 파일 `core/ui/src/main/java/com/dororong/rodi/core/ui/components/RodiButton.kt`:

```kotlin
package com.dororong.rodi.core.ui.components

import androidx.compose.foundation.BorderStroke
import androidx.compose.foundation.layout.fillMaxWidth
import androidx.compose.foundation.layout.height
import androidx.compose.foundation.shape.RoundedCornerShape
import androidx.compose.material3.Button
import androidx.compose.material3.ButtonColors
import androidx.compose.material3.ButtonDefaults
import androidx.compose.material3.Text
import androidx.compose.runtime.Composable
import androidx.compose.ui.Modifier
import androidx.compose.ui.graphics.Shape
import androidx.compose.ui.unit.dp
import com.dororong.rodi.core.ui.theme.RodiRadius
import com.dororong.rodi.core.ui.theme.RodiTheme

enum class RodiButtonVariant { Primary, Secondary }

/** RodiButton 기본값(높이/모양/색상)을 한 곳에서 계산하는 헬퍼. */
object RodiButtonDefaults {
    val Height = 48.dp

    @Composable
    fun shape(): Shape = RoundedCornerShape(RodiRadius.md)

    @Composable
    fun colors(variant: RodiButtonVariant): ButtonColors = when (variant) {
        RodiButtonVariant.Primary -> ButtonDefaults.buttonColors(
            containerColor = RodiTheme.colors.primary600,
            contentColor = RodiTheme.colors.white,
            disabledContainerColor = RodiTheme.colors.gray300,
            disabledContentColor = RodiTheme.colors.gray500,
        )
        RodiButtonVariant.Secondary -> ButtonDefaults.buttonColors(
            containerColor = RodiTheme.colors.white,
            contentColor = RodiTheme.colors.gray800,
            disabledContainerColor = RodiTheme.colors.gray100,
            disabledContentColor = RodiTheme.colors.gray400,
        )
    }

    @Composable
    fun border(variant: RodiButtonVariant): BorderStroke? = when (variant) {
        RodiButtonVariant.Primary -> null
        RodiButtonVariant.Secondary -> BorderStroke(1.dp, RodiTheme.colors.gray300)
    }
}

/**
 * Rodi 공용 버튼. 기본 높이 48dp, 기본 모양 [RodiRadius.md].
 * 기존 화면(ParkingDetailContent 등)처럼 모양을 다르게 써야 하면 [shape]를 오버라이드한다.
 */
@Composable
fun RodiButton(
    text: String,
    onClick: () -> Unit,
    modifier: Modifier = Modifier,
    variant: RodiButtonVariant = RodiButtonVariant.Primary,
    enabled: Boolean = true,
    shape: Shape = RodiButtonDefaults.shape(),
) {
    Button(
        onClick = onClick,
        enabled = enabled,
        modifier = modifier
            .fillMaxWidth()
            .height(RodiButtonDefaults.Height),
        shape = shape,
        colors = RodiButtonDefaults.colors(variant),
        border = RodiButtonDefaults.border(variant),
    ) {
        Text(text, style = RodiTheme.typography.button1)
    }
}
```

`RodiButtonVariant.Secondary`는 현재 화면에서 쓰이지 않지만 컴파일되는 완결된 스타일로 넣어둔다
(임의 색상 발명이 아니라 위 코드의 값을 그대로 사용 — gray100/white/gray800/gray300/gray400 전부
`RodiColors`에 이미 존재하는 토큰).
