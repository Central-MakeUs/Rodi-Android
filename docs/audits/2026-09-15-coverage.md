## 재현 방법

```bash
./gradlew verifyRoborazziDebug koverXmlReport   # build/reports/kover/report.xml (JaCoCo XML 형식)
```

`verifyRoborazziDebug`를 반드시 함께 준다. Roborazzi 테스트는 verify 모드일 때만 컴포저블을 렌더링해서, 빼면 `core:ui`·`feature:home`이
낮게 나온다(이 조사 시점에 합계 11,632줄, 47.9%). CI의 `kover-report`와 같은 조건이다.

모듈 구분은 **패키지 접두사**로 한다(`com.dororong.rodi.core.data` → `core:data`, 어느 모듈 접두사에도 안 맞는
`com.dororong.rodi.*`는 `app`). 수치는 모두 **LINE** 카운터다.

```bash
python3 - build/reports/kover/report.xml <<'PY'
import sys, xml.etree.ElementTree as E, collections
mods = ["core.common","core.data","core.domain","core.ui","feature.auth","feature.course.registration",
        "feature.entry","feature.home","feature.mypage","feature.settings"]
def line(el):
    for c in el.findall("counter"):
        if c.get("type") == "LINE": return int(c.get("missed")), int(c.get("covered"))
    return 0, 0
agg = collections.defaultdict(lambda: [0, 0])
for p in E.parse(sys.argv[1]).getroot().iter("package"):
    n = p.get("name").replace("/", ".").removeprefix("com.dororong.rodi.")
    m = next((x for x in mods if n == x or n.startswith(x + ".")), "app")
    mi, co = line(p); agg[m][0] += mi; agg[m][1] += co
    for f in p.findall("sourcefile"):
        fm, fc = line(f)
        if fc == 0 and fm > 0: print("0%", m, n, f.get("name"), fm)
for m, (mi, co) in agg.items(): print(m, co, mi + co, round(100 * co / (mi + co), 1))
PY
```
